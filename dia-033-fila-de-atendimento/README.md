# Dia 33 implementar fila de atendimento (SIMULAR)

## Descrição

A lógica deste programa é a mesma do dia 31 fila queue, mas o que mudou foi renomear as funções e o nome das variáveis tornado mais realistas. Em problemas reais a fila de atendimento é uma fila de espera, onde os clientes esperam na fila de espera para ser atendido.

## Lógica

* criar uma fila de atendimento, ou seja, um array
* criar 3 funcões atender(), proximoCliente() e entrarNaFila(). Essas funções seguem a mesma lógica do dia 31
