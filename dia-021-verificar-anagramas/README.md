# Dia 021 - Verificar Anagramas

Este é um programa PHP que verifica se duas palavras são anagramas. Um anagrama é uma palavra formada pelas mesmas letras de outra palavra, mas em uma ordem diferente.

## Lógica

O programa usa uma abordagem baseada em hashmap para verificar se as palavras são anagramas. Ele compara a frequência de cada letra 
nas duas palavras e verifica se elas são iguais. Se forem iguais, as palavras são anagramas.
