# Dia 44 - Encontrar Primeiro Caracter Unico

## Descrição

Esse desafio consiste em encontrar o primeiro caractere unico em uma string. Usando estruturas de repetição e funções.

## lógica

1. Criar uma funcao que recebe uma string e retorna o primeiro caractere unico da string.

2. Usar uma estrutura de repeticao para percorrer a string e contar a quantidade de vezes que cada caractere aparece.

3. Usar uma estrutura de repeticao para percorrer a string novamente e encontrar o primeiro caractere unico.

4. Caso nao encontre nenhum caractere unico, retornar "" ou null.
