# Dia 29 mini sistema de login CLI

## Descrição 

Este desafio consiste numa simulação de um login na linha de comando (CLI). 

# Exemplos
```php
Usuário:
admin

Senha:
123456

Bem-vindo gustavo.
```
# Lógica

* Armazenar um utiliazador
* Peça login ao utilizador
* Verifique as credenciais
* Informar se o login foi bem sucedido.
