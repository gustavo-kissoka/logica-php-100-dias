# Dia 32 implementar pilha (STACK MANUAL)

## Descrição

Este projeto tem como objetivo implementar uma pilha (stack) manualmente utilizando uma estrutura de dados personalizada. A pilha é uma estrutura de dados do tipo LIFO (Last In, First Out), onde o último elemento inserido é o primeiro a ser removido.

## Lógica

* criar uma pilha  ["A", "B", "C"]
* criar 3 funções empilhar(), desempilhar() e topo() -> empilhar adiciona um novo elemento na pilha, pop remove um elemento da pilha e top mostra o topo da pilha
* remove um elemento da pilha usando a função em php array_pop() -> remove o ultimo elemento da pilha
* empilha um novo elemento na pilha usando a função em php array_push() -> adiciona um novo elemento na pilha
* mostra o topo da pilha usando a função em php end() -> mostra o ultimo elemento da pilha
 
## Extras

* criar uma funcao que verifica se a pilha esta vazia usando a funcao em php empty()
* criar uma funcao que mostra o tamanho da pilha usando a funcao em php count()
