# Dia 26 Interseção de dois arrays frequência de elementos

## 🧠 Descrição

Este programa recebe dois arrays onde dever retornar apenas os elementos que existem nos dois arrays.

## 📌 Exemplo

### Entrada

```php
$arr1 = [1, 2, 2, 1];
$arr2 = [2, 2];
```

### Saída

```php
[2, 2]
```

---

## 💡 Conceitos Aplicados

* Hashmap
* Frequêmcia de elementos
* Arrays
* Comparação eficiente
