# 🎬 Sistema de Reserva de Assentos (Cinema)

Sistema desenvolvido em **PHP (CLI)** que simula a reserva de assentos de uma sala de cinema. O utilizador pode visualizar a sala, reservar e cancelar assentos, além de consultar estatísticas de ocupação.

## 🚀 Funcionalidades

* Visualizar o mapa de assentos
* Reservar um assento
* Cancelar uma reserva
* Validar assentos informados pelo utilizador
* Exibir estatísticas da sala
* Menu interativo em linha de comandos (CLI)

## 🛠️ Tecnologias

* PHP
* Terminal (CLI)

## ▶️ Como executar

Certifique-se de ter o PHP instalado e execute:

```bash
php sistema_cinema.php
```

## 📚 Conceitos praticados

* Matrizes (arrays bidimensionais)

* Estruturas condicionais
* Estruturas de repetição
* Funções

* Validação de entradas
* Organização de código por responsabilidades

## 🏛️ Arquitetura

O sistema foi desenvolvido utilizando o princípio de **divisão de responsabilidades**, onde cada função possui uma tarefa específica, tornando o código mais organizado, reutilizável e fácil de manter.

## 📈 Complexidade

As principais operações possuem complexidade **O(n × m)**, sendo **n** o número de filas e **m** o número de assentos por fila.

## 🔮 Melhorias futuras

Este projeto pode ser expandido com novas funcionalidades, como:

* Reservar vários assentos simultaneamente
* Identificar o cliente responsável por cada reserva
* Pesquisar assentos livres consecutivos

* Interface gráfica ou versão web
* Utilização de cores no terminal para diferenciar assentos livres e ocupados
