# Dia 34 sistema de notas

## Descrição

Neste projeto, criei um sistema de notas para estudantes. O sistema permite calcular a média geral. Além disso, o sistema também pode determinar se o estudante foi aprovado ou reprovado com base na média calculada.

## Lógica

* criar um array para armazenar as notas dos alunos
* criar 2 funções para calcular a média geral e verificar se o estudante foi aprovado ou reprovado, dividindo responsabilitades.
* usar foreach para percorrer o array e verificar a maior nota e a menor nota (dia 007)
* usar if/else para verificar se o estudante foi aprovado ou reprovado
