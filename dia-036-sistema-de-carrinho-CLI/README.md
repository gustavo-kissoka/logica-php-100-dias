# Dia 36 sistema de carrinho CLI

## Descrição

Este sistema de carrinho de compras consiste em um programa que permite ao usuário adicionar e remover produtos do carrinho, bem como calcular o valor total da compra.

## Lógica

* criar um array para armazenar os produtos do carrinho
* criar 3 funções adicionarProduto, listarProdutos e calcularTotal -> adicionarProduto adiciona um produto ao carrinho, listarProdutos mostra os produtos do carrinho e calcularTotal calcula o valor total da compra
