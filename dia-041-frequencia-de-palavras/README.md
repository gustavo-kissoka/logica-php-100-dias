# Dia 41 Palavra mais frequente

## Descrição

Este programa recebe um texto e calcula a palavra mais frequente no texto e a quantidade de vezes que ela aparece.

### Lógica

* Criei duas funções que retornam as palavras mais frequentes e a quantidade de vezes que ela aparece.
* O programa recebe o texto e chama as funções para calcular as palavras mais frequentes e a quantidade de vezes que ela aparece.
* usei o explode para dividir o texto em palavras e o strtolower para converter as palavras em minúsculas.
* criei um array "frequencia" para armazenar a frequência de cada palavra.
* usei um loop "foreach" para percorrer o array de palavras e contar a frequência de cada palavra.
* na segunda função "palavraMaisFrequente" usei o array "frequencia" para encontrar a palavra mais frequente e a quantidade de vezes que ela aparece.
