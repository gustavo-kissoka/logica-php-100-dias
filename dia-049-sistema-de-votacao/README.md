# 🗳️ Sistema de Votação (CLI)

Um sistema de votação desenvolvido em **PHP** para execução no terminal (CLI). O projeto permite cadastrar candidatos, registrar votos, visualizar resultados parciais e identificar o vencedor da eleição.

## 🚀 Funcionalidades

* Cadastro de candidatos
* Registro de votos
* Validação de candidatos
* Exibição dos resultados parciais
* Identificação do vencedor atual
* Encerramento da votação

## 🛠️ Tecnologias

* PHP
* Terminal (CLI)

## ▶️ Como executar

1. Certifique-se de ter o PHP instalado.
2. Execute o arquivo no terminal:

```bash
php sistema_votacao.php
```

## 📈 Complexidade

As principais operações, como votação e busca pelo vencedor, possuem complexidade **O(n)**, onde **n** representa a quantidade de candidatos.

## 🔮 Melhorias futuras

Este projeto pode ser expandido com diversas funcionalidades, como:

* Persistência dos dados em arquivos ou banco de dados
* Identificação dos eleitores para impedir votos duplicados
* Exibição da percentagem de votos de cada candidato
* Suporte a múltiplas eleições
* Registro de logs das votações
