# 🚀 Dia 24 — Rotacionar Array

## 🧠 Descrição

Este desafio consiste em rotacionar um array para a direita `k` vezes.

---

## 📌 Exemplo

### Entrada

```php
[1,2,3,4,5]
k = 2
```

### Saída

```php
[4,5,1,2,3]
```

---

## ⚙️ Lógica Utilizada

Foi utilizada a técnica de reversão de array:

1. inverter a parte esquerda
2. inverter a parte direita
3. inverter o array completo

Também foi utilizada passagem por referência (`&`) para modificar diretamente o array original dentro da função.

---

## 💡 Conceitos Aplicados

* Manipulação de arrays
* Algoritmo de reversão
* Passagem por referência
* Controle de índices
* Complexidade O(n)

---
