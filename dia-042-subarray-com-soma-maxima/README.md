# Dia 42 Maximum Subarray Sum (Kadane's Algorithm)

## Descrição

Este projeto resolve o clássico problema de encontrar a **maior soma possível de um subarray contínuo** em um array de números inteiros (positivos e negativos).

### Exemplo:

```php
Input: [-2, 1, -3, 4, -1, 2, 1, -5, 4]
Output: 6
Explanation: O subarray contínuo com a maior soma é [4, -1, 2, 1], que soma 6.
```
## Conceitos aplicados
* Algoritmos Greedy
* Otimização de arrays
* Programação dinâmica (base)
* Análise de complexidade

## Melhorias futuras
- Retornar o subarray responsável pela maior soma
